# Easter Egg - Juice Shop (⭐⭐⭐⭐)

## 挑战目标
找到并下载隐藏的复活节彩蛋文件

## 漏洞类型
路径遍历 + 空字节截断（Null Byte Injection）

## 环境信息
- 靶场：Juice Shop
- 难度：四星
- 日期：2026-05-06


## 复现步骤

### 1. 访问 FTP 目录
http://localhost:3000/ftp
发现文件列表中有 eastere.gg

### 2. 尝试直接下载
http://localhost:3000/ftp/eastere.gg
返回 403 Forbidden（服务器只允许下载 .md 和 .pdf）

### 3. 使用空字节截断绕过
http://localhost:3000/ftp/eastere.gg%2500.md
文件成功下载 ✅

### 4. 验证成功
Score Board 中 Easter Egg 变绿 ✅

---

## Payload 详解

| 编码 | 含义 |
|------|------|
| %25 | URL 编码后的 % 符号 |
| %2500 | %00 的二次 URL 编码（双重编码） |
| %00 | 空字节（Null Byte），在 C/文件系统中表示字符串结束 |
| .md | 欺骗服务器：我要下载一个 markdown 文件 |

### 解析过程
1. 服务器第一次解码：%25 → %，得到 %00.md
2. 服务器第二次解码：%00 → 空字节（字符串终止符）
3. 程序以为文件路径是 /ftp/eastere.gg（后面的 .md 被忽略）
4. 绕过后缀检查，成功下载

---

## 原理说明

空字节截断（Null Byte Injection）：在某些旧系统或语言（如 C、PHP < 5.3）中，
空字节（\0）被当作字符串结束符。攻击者在文件名后插入 %00.md，
服务端在检查后缀时看到的是 .md（通过后缀检查），但在实际读取文件时，空字节截断了后面的内容，只读取了 /ftp/eastere.gg。

一句话总结：后缀检查通过，但文件读取时被截断，导致绕过。

---

## 修复建议

1. 使用白名单校验文件后缀，而不是黑名单
2. 更新语言/框架版本（PHP 5.3+ 已修复空字节问题）
3. 对用户输入进行严格过滤，删除 %00 或 \0
4. 使用编程语言提供的安全文件 API
